🕹️ **How to use**

Download and extract the entire folder from the .zip (do not open the files from inside WinRAR/7zip, extract everything to a folder).

Open the game in MuMu Player and go to the Sparrow Race home screen (where the "Start Matching" button appears).
This screen here

Then double-click on **Macro Sparrow Race.exe**.

A black terminal window will open with the logs. This is the program running, you can check if it is working normally or if any error has occurred.

**TO STOP:** Click on the bot's black window and press Ctrl + C or just close the terminal.

After the Macro starts, you **DO NOT** need to leave MuMuPlayer on the main screen. The macro works even with the emulator minimized if you want to do something else on the computer while the macro runs.

❗️❗️ The macro is configured to run with the game in **English** and in one of the 3 supported resolutions, if anyone needs it let me know here and I'll create a version with the game in Spanish or in some other resolution
